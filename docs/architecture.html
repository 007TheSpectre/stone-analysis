Cypher Flow

sequenceDiagram
    participant CLI as main.cpp
    participant WR as WavReader
    participant CM as CharMap
    participant CYP as Cypher
    participant DFT as Dft
    participant IDFT as Idft
    participant WW as WavWriter

    CLI->>WR: open in_file
    WR-->>CLI: samples, rawHeader

    CLI->>CM: normalizeMessage(message)
    CM-->>CLI: lowercase, validated

    loop for each character window
        CLI->>CYP: encode(samples, message)
        CYP->>DFT: transform(window)
        DFT-->>CYP: spectrum X[k]
        CYP->>CM: addSinusoid(spectrum, bin, magnitude)
        CYP->>IDFT: transform(spectrum)
        IDFT-->>CYP: real samples clamped to int16
    end

    CYP-->>CLI: encoded samples
    CLI->>WW: write(out_file, rawHeader, encoded)

Decypher Flow

sequenceDiagram
    participant CLI as main.cpp
    participant WR as WavReader
    participant DEC as Decypher
    participant DFT as Dft
    participant CM as CharMap

    CLI->>WR: open in_file
    WR-->>CLI: samples

    loop for each 2400-sample window
        CLI->>DEC: decode(samples)
        DEC->>DFT: transform(window)
        DFT-->>DEC: spectrum X[k]
        DEC->>DEC: find peak bin in 1001..1037
        alt peak >= DETECT_THRESHOLD
            DEC->>CM: binToChar(peak_bin)
            CM-->>DEC: character
        else bin == ULTRASOUND_BASE_BIN
            DEC->>DEC: stop (terminator)
        end
    end

    DEC-->>CLI: decoded message string

Steganography Design

graph TD
    A["Message text"] --> B["normalizeMessage()\nlowercase + validate"]
    B --> C["Split into characters"]
    C --> D["For each character:\ncharToBin(c) → bin k"]
    D --> E["Slice 2400 samples\n~50 ms window"]
    E --> F["DFT: time → frequency"]
    F --> G["addSinusoid(X, bin, 10000)\nX[k] += magnitude * exp(i*phase)\nX[N-k] = conj(X[k])"]
    G --> H["IDFT: frequency → time"]
    H --> I["Clamp to int16\nwrite window"]
    C --> J["Append terminator window\nbin = ULTRASOUND_BASE_BIN (1000)"]
